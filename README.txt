HAUSVERWALTUNG APP – VERSION 7 LOKAL

Diese Version arbeitet vollständig lokal und offline.

WICHTIG:
- Alle Daten werden nur im Browser auf diesem Gerät gespeichert.
- Es gibt noch keine Server- oder NAS-Synchronisierung.
- Bestehende Daten aus Version 6 und älteren Versionen werden automatisch übernommen.
- Exportiere regelmäßig unter Mehr > Datensicherung eine JSON-Sicherung.

NEU:
- Fehler im Kostenplan behoben.
- Müllkalender kann die übrigen Module nicht mehr blockieren.
- Jedes Modul besitzt eine eigene Fehlerabsicherung.
- Sichtbare Anzeige, ob die Daten lokal gespeichert wurden.
- Lokaler App-Modus mit später optionaler NAS-Anbindung.
- Monats-, Jahres- und Pro-Person-Kosten bleiben enthalten.

START AM PC:
1. ZIP entpacken.
2. Im Ordner immobilien_app ein Terminal öffnen.
3. python -m http.server 8080
4. Im Browser http://localhost:8080 öffnen.

INSTALLATION AUF DEM HANDY:
Die Dateien auf einen lokalen oder öffentlichen Webserver laden, in Safari/Chrome öffnen
und „Zum Home-Bildschirm“ bzw. „App installieren“ wählen.
